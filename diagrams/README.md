# Atmosight CSV pipeline diagrams

Open `index.html` in a browser for all three diagrams. Everything is local; no internet connection or Mermaid installation is required. Each SVG is a scalable standalone diagram. Each `.mmd` file is editable Mermaid source.

1. Upload and compatibility
2. Row validation and model selection
3. Results, explanations and exports

Regenerate with `backend/.venv/Scripts/python.exe diagrams/build_diagrams.py` from the project root. Generated from the implemented 1.1.1 workflow in backend/import_analysis.py, backend/app.py and Design/src/App.tsx.
