Reading the branches: Every selected model in diagram 02 proceeds to diagram 03. Invalid rows are retained and skipped; they do not stop other valid rows. Quality-only analysis does not run models, but invalid mapped measurements can still generate row errors. Reference metrics use only predicted rows with exact recognized category labels; macro F1 includes all six classes, including absent-class zeros. A quality-only dataset with no pollutant mappings can contain valid negative values such as temperatures.

File errors versus warnings: File/configuration errors require correction and resubmission. Duplicate observations, date gaps, screening ceilings and anomaly flags are reported without automatic removal. Date/station diagnostics require recognized column names and parseable ISO dates; there is no timezone conversion or gap filling. A missing specialist model falls through to the next supported route; a model loading/inference failure may fail the analysis request.
